# Consultor de Enquadramentos — Pós-registro ANVISA

Consulta rápida, pensada para celular, dos enquadramentos de mudanças pós-registro:
**RDC 73/2016** (medicamentos), **RDC 443/2020** (testes, limites e métodos analíticos) e **RDC 359/2020** (IFA/DIFA).

Para cada mudança: documentos necessários, rota de implementação (HMP · imediata · aguarda deferimento), condições, concomitâncias e a descrição da norma.

**Acesse:** https://rodolfoortigara-gif.github.io/consultor-enquadramentos/
No celular, use "Adicionar à Tela de Início" para usar como app (funciona offline).

> Resumo **não oficial**, apenas orientativo. A decisão regulatória é do profissional responsável. Confira sempre a norma vigente e a redação oficial publicada pela ANVISA.
